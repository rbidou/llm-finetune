Setup

Where this application writes what it produces, and where its web server listens

Model directory

default

Training checkpoints, LoRA adapters, merged models and quantized GGUF files are all written under this directory, grouped by base model. It is created if it does not exist. Existing artefacts are not moved: they stay where they were written.

{# Folders are listed by the server: a browser will not reveal the absolute path of a folder picked with its own dialog. #}

Web server

default

127.0.0.1 keeps the interface on this machine; 0.0.0.0 listens on every network interface. Changes apply the next time the web server starts (python run.py web).

Other machines on the network will reach this server. It has no authentication and can read local files and start processes.
